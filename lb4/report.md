## Контрольні питання

1. Чому не можна формувати Expected Response на основі Actual Response?
бо очікувана відповідь має відповідати вимогам.

2. Для чого використовується Postman Collection?
для зберігання запитів.

3. Для чого використовується {{baseUrl}}?
для зберігання адреси сервера.

4. Що таке Postman Sandbox?
середовище для виконання JavaScript.

5. Що таке об'єкт pm?
об'єкт для роботи з тестами та відповідями.

6. Для чого використовується pm.response?
для отримання відповіді сервера.

7. Що повертає pm.response.json()?
JSON у вигляді JavaScript-об'єкта.

8. Для чого використовується pm.test()?
для створення тестів.

9. Що є першим аргументом pm.test()?
назва тесту.

10. Що знаходиться у callback pm.test()?
функція перевірки.

11. Для чого використовується pm.expect()? для перевірки значень.

12. Що є Actual Value у pm.expect(actual).to.eql(expected)?
фактичне значення.

13. Для чого використовується .to.eql()?
для порівняння значень.

14. Для чого використовується .to.have.property()?
для перевірки наявності властивості.

15. Для чого використовується .to.be.a()?
для перевірки типу даних.

16. Чому один Request може містити декілька Tests?
бо один запит може мати декілька перевірок.
